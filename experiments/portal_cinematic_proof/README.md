# Portal Cinematic Proof

This experiment is the reproducible, research-only motion-direction surface for RQ-125. It does not ship in the web
bundle and does not contain generated media.

- `motion-contract.json` freezes the confirmed source identity, eight motion systems, the 192-frame clock, research-only
  output policy, quality gates, and corrected-A fallback.
- `index.html` uses only local HTML/CSS/SVG. The mother image remains the locked structure layer; deterministic overlays
  establish motion coverage before any organic plate model is called.
- `scripts/render_portal_cinematic_proof.py` copies this composition and the confirmed source into a repository-external
  scratch directory, invokes an already-vetted exact HyperFrames 0.8.14 installation with telemetry/auth disabled, then
  encodes a compatibility preview with fixed FFmpeg settings.

Passing this proof means only that the hybrid motion language is worth continuing. It does not adopt HyperFrames as a
product dependency, approve a production loop, or close Portal/Account Task 5.
