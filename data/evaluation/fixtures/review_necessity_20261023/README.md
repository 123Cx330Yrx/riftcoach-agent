这是值得检验的机制假设，尚未证明是根因或有效修法。相对只重复禁令，它提供具体判定步骤；
相对加一个审查模型或复杂分区schema，它保持现有职责和调用数量。但模型可能仍误判、
过度宽松或仅记住示例，因此必须同时看正确稿、真错稿和意见/修法全文。
