## 候选机制及竞争解释

现有政策已经要求按全文、保留正确内容；现有输入可逐字重建，未发现确定性的来源/限定丢失。
“模型把练习一词补成个人参赛”是本次输出中的解释错误，不是已证实的模型根因。

候选只显式给出判定顺序：实际义务→全文对象/行动→是否真实缺失或冲突→最小补丁保留检查。
它使用域外展览例，不塞入本案段号、数字或预期答案；不新增字段、职责、自动语义过滤器或调用数。

会生成四稿各自的baseline/candidate业务请求及manifest，共8份请求材料；这不是8次调用计划。
