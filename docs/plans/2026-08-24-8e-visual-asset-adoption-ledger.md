# 8E Visual Asset Adoption Ledger

This ledger is the supply-chain boundary for the approved
`Rift Awakening → Broadcast Workbench` direction. A row is not an adoption
because a reference looks attractive; it becomes adopted only after a concrete
consumer, license/evidence, responsive fallback, reduced-motion behavior,
performance cost, and removal path are recorded.

## Adoption gates

Before a row moves from research/preview to shipped:

1. The consumer exists in a real product contract; a visual reference cannot
   create a Timeline, Training plan, rank, or evidence claim.
2. The source, license, and redistribution boundary are recorded. Prompt
   metadata alone is not a license.
3. The mechanism works at 1440, 1024, 390, and 320 pixels, has keyboard/focus
   semantics, and has a reduced-motion/static fallback.
4. The bundle and runtime cost are measured. CSS/SVG is preferred for simple
   geometry; an extra animation engine needs a reproducible Bad Case.
5. The visual can be removed without changing the data/control flow. The
   product must remain honest and usable with the row disabled.

## Current conclusion

The foundation journey still runs on self-authored semantic DOM/SVG/CSS and the
existing Motion runtime, but RQ-108/RQ-110/RQ-112 supersede its visual runtime.
The user-confirmed original mother image is now the only Portal source master;
the dark background, aperture, keyframe and CSS crystal cannot ship as the
final poster/loop/fallback. Normal Portal and Account must use distinct
full-frame global loops with same-source posters, while DOM owns only text,
locale, the transparent crystal hit target and bounded activation choreography.

No Account source master or video is accepted yet. One-shot five-hero concepts,
the mechanical track base and splash-cutout look are rejected. The current
design gate requires recognizable official topology, intentional terrain
abstraction without invented micro-detail, explicit blue/red sides, a flat
right panel zone and five separately resculpted scene-native hero echoes before
Account media can enter runtime.
