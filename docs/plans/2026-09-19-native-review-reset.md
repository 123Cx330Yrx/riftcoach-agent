## Small response contract

The host supplies the complete report with stable block numbers and the complete
original sources with root source numbers and type/provenance. The model reviews
every block, including titles, in one table: block, kind, selected sources,
explanation and actual problems. Problems contain category/severity, explanation
and correction. Host locates the whole original block; the model does not rebuild
quote spans, source paths, scalar formats or duplicate arithmetic operand lists.

Full-block review is a responsibility record, not proof that every sentence was
understood. Source IDs prove provenance, not entailment. Numeric accuracy,
intended sample, negation, mixed facts, causal/long-term claims, identity, user
goals and actionable source use remain model judgments tested by independent
controls and manual inspection. A meaningful tail cannot be dropped from input.

A complete valid evaluation ends in one call. Only a recoverable output-contract
error permits one complete reassessment, preserving raw first output, all
identified first problems and explicit dispositions. High-risk injection is
terminal before reassessment. No invisible retry, truncation or invented score.
One report revision, followed by fresh evaluation on the identical sources,
remains the only revision route. Normal path uses three calls when revision is
needed; worst-case two evaluations plus revision still uses at most five.
