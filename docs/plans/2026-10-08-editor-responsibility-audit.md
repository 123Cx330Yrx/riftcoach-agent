# 编辑职责复核：不再把尾链变体当成初评修法

## 结论及当前决定

本工作包完成原始公开回执对照，未修改模型或生产代码，未调用Provider。
当前四字段编辑器无旧意见的同条件对照，在本次核对的五份封存中不存在；不能宣称它已被
原样实测否定。但“无旧意见”既不新颖，也没有证据能单独保证纠错，更无法修复之前的
GLM初评误报。**不据此准备下一批付费尾链，不实施pass后强制编辑，不再扩编辑协议。**

保留五份封存里的单例编辑成功证据。当前必要编辑→fresh的单例成功另见本组之外的
`golden_review_bound_original15_result_20261008.json`及`2026-10-08-review-bound-original15-result.md`，
不能声称本次五份审计证明了完整fresh路径有效。原15的2/15也来自上述项目资格记录，
本脚本不重新计算资格。当前阻断是完整初评对全文范围
的判断不一致；产品资格仍要求该环节自身正确，不能用编辑的成功抵消。没有已验证的通用修法。

## 实际代码接缝及方案取舍

`golden_native_issues_review.request`把accepted_review写入真实编辑输入；
`golden_native_business_policy.REVISION_POLICY`要求依据它的实际问题和完整来源修订。
`review_bound_editor.edit_request`只替换编辑交付协议，仍保留完整意见；
`inspect_exchange`证明请求、定位与成稿身份，不证明修改理由成立。
原始误报在此之前的完整初评已出现。修改这些编辑接缝不能追溯修复初评。

| 备选 | 决定与原因 |
|---|---|
| 当前四字段编辑完全不看旧意见 | 暂不准备付费。可研究意见暴露，但删整个意见也将任务从按问题编辑改为独立找错；一次结果不隔离全部因果，且初评资格不变 |
| Host只删block4误报，保留block6真错 | 不作为自主产品修法。Host先知道答案才能筛选；至多是标明答案辅助的研究干预，不是Agent自动排错能力 |
| 只删评分、改accepted_review名称或补一句全文提醒 | 没有区分性证据，不安排近义变体；当前规则本已要求全文和只修真错 |
| 重开完整重评或增加专审 | 既有重评已实测误报；正常2生成+初评+重评+编辑+fresh为6调用，不满足现有出口 |
| 恢复竞争范围自选audit | ADR0116后续实测已有问题清单正确但audit漏项，不采用为通用修法；不再要求模型多填字段来证明自己已理解 |
| 降低初评门，只检查最终报告 | 涉及用户采用标准和ADR0111；本轮不修改，不把诊断例外推广为产品政策 |

独立Agent核对认为“无旧意见”尚有研究区分价值，建议只移除误报作为对照；主审保留前者
的证据限定，但因后者依赖Host答案且不解决初评出口，未采用为下一付费或产品方案。
这是方案复核，不是本批模型阶段双审，也没有新增语义通过事件。
新增脚本与文档的独立复核指出完整fresh成功及2/15不属于这五封存的推论；已补外部
证据链接，并删去脚本硬编码的资格数。离线重放与保存摘要一致，治理及diff检查通过。

## 下一工作包与结束判据

返回**完整初评的任务与输入表示选择**，不继续修改后续编辑器。先对照当前真实初评请求和
已关闭的完整重评/竞争范围audit证据，明确哪个生产者或任务责任能发生实际变化、哪条
反例能区分该变化。不得把“让模型更注意全文”充作机制，也不声称已找到模型内部根因。

可实施方案必须同时满足：完整报告及来源不变；正确全文和混合真错都可表达；初评及fresh
用相同新合同；保留原五调用/预算/来源与安全门；无Host答案过滤。若候选只是复制旧失败
或不能改变初评路径，就明确淘汰，不建新runner、不申请付费。独立产品依赖仍照活动计划保留，
不以这项阻断宣布整项目停工，也不拿外围交付冒充该语义问题已修好。

本包完成的是证据核清和撤销不充分的尾链推进方向；不是模型质量修复或8E收尾。
