# ADR0112 — 独立接入粗来源合同，先验证真实纠错链

2026-09-25。状态：采用显式工程接线；质量和生产准入未采用。

## 问题与证据

旧1.5.2原15严格资格为历史8/15，observed:2首评有引用覆盖缺口。
粗来源两控制的真实输出分别正确阻断未来全称外推、放行完整上下文正确稿，
全部解释和引用经主/独立检查接受。见 golden_coarse_source_result_v1.json。
这支持继续集成，不证明稳定性、因果根因或完整任务已合格。

原工作流补齐编辑/fresh终评后，实际factory仍以旧投影拒绝请求。
不能伪装旧metadata或另造临时router取代现有共享预算、Trace和来源约束。

## 决定与代价

新增opt-in合同1.5.3，独立Skill0.6.2/Program3.2.0/evaluation3.6.0及资产目录。
复用现有角色路由、运行观察、预算、修订状态机和应用保存机制。
Flash/high生成/编辑、GLM/high审查，原5调用/401920tokens/900秒、单次300秒、
32768输出、retry0、最低85分及完整上下文标准均保持。

同一projection贯穿路由、provider包装、预算身份、实际回执读取和用量汇总。
合同核对provider身份；审查请求校验实际来源地址与动态根schema，不仅信metadata。
可信Trace核对精确snapshot及Skill/Program版本。manifest绑定实际策略和实现；
共享代码变更诚实刷新旧当前manifest，旧真实证据只保留其封存身份，不迁到新合同。
旧关闭preview仍核对原封存包、计划与完整请求，非关闭资格比较不放宽。

增加一个显式builder和profile的维护成本，用于来源合同隔离；不增加模型或状态机。
默认Worker不切换，不把模拟published等同生产采用。

## 验证与后续

先验证实际factory/预算/回执的编辑和fresh终评，以及完整应用生成/工具/审查/保存，
覆盖人工拒绝、协议失败、超时未知用量、新旧冒认和历史回放。
同HEAD公共检查通过后，沿用已授权有界尾部实测：注入原已接受首评，
仅新发Flash编辑和GLM fresh终评，最多2调用/193536tokens/600秒，
保守全GLM未缓存预留估价2.859008元，非账单。两阶段均须主/独立完整来源接受；
任何错误停止，无重试或提示变体。初评旧成本不重复计算，不能拼成连续真实任务。

此前coarse_role_qualification仅准备原15和回放；后继已接既有严格审计机制，资格仍待真实全15验证。
新质量标志保持false；尾段通过后接同身份原15完整审计与自然Agent任务，
再验证Worker/DB/API/Workbench消费。Coach/Review/Training/Evidence、前端审美/头像、
个人训练、Memory及两树整合沿既有路线追踪，本ADR不重新划分阶段。
