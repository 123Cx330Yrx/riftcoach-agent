# ADR-0095：候选教练查询补全与有界本地补查

- 状态：Accepted for offline implementation
- 日期：2026-09-05
- 范围：RQ-236 / Stage 8 / 8E；不注册产品候选，不运行真实考卷

## 问题与选择

RQ-235 已确认两次检索均成功执行但零片段，最后为 insufficient_evidence；原始查询未留存，
不能证明具体词句。独立开发用例“复盘”在非空语料中可复现零命中，更明确的概念可命中。
原因是通用自然语言查询与小型中文教练语料的检索支持合同存在衔接缺口。

选择在候选作用域内增加版本化查询补全，而非全局降低支持阈值或引入新检索依赖：

1. 原查询先走原检索器，已有命中完全沿用；
2. 仅在 insufficient_evidence 且查询精确匹配预先登记的通用教练主题别名时，保留原查询、
   top_k 和全部过滤条件，添加该主题的固定概念词，最多再查一次；
3. 不识别任意子串，不读取案例答案或玩家数据生成补全；无关查询、无适用资料、冲突、异常不补查；
4. 候选可信上下文提示模型使用明确的中文教练概念；仍无结果时必须保留缺证据状态，不能补引用；
5. 每次本地尝试只投影主题枚举、查询词数、过滤键名、候选/适用/支持/返回计数和原因枚举。

## 边界

新策略为 coaching-query-recovery-v1，ProductionDomainCaseExecutor 默认关闭，只有显式候选
请求策略及质量加固同时存在才可开启。旧 V2/V3 入口拒绝带新检索策略的执行器，防止旧身份
消费新行为。默认 Runtime、GLM-5.2、前端、知识库、支持阈值、评分门和模型预算不变。
最多两次本地检索/工具调用，不增加模型/API 重试；本批只用独立开发数据及 Fake Provider。

## 验证与后续

覆盖短查询零命中到真实来源、现有命中不变、未知主题不补查、过滤/冲突/异常不绕过、双语别名、
仍无证据拒绝、脱敏诊断严格解析和旧回执字节一致性；完整离线 Agent→检索→Evidence→评测
测试必须通过。新策略未来进入真实版本前须绑定上下文、预算和证据身份，本批不重跑 RQ-235。
