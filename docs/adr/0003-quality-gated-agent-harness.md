# ADR-0003：采用质量门控型 Agent Harness

- 状态：接受
- 日期：2026-07-16

## 背景

教练报告包含确定性比赛数字和模型解释。单次 LLM 生成容易出现数字错误、相关性因果化和超出证据的训练建议。

## 决策

正式运行时采用以下生命周期：

```text
事实收集 → 知识检索 → 草稿生成 → 独立评测
→ 受限修订 → 再评测 → 发布、拒绝或确定性降级
```

每次运行必须记录 `run_id`、状态、证据、Prompt/模型版本、评测结果、修订次数和最终发布决定。

## 影响

增加模型调用和实现复杂度，但能够建立可验证的质量闭环。阶段 2 将把现有脚本原型正式重构为 Harness。
